# Painel Comercial UNIFAHE — protótipo visual

Frontend estático criado para validar a estrutura visual e a diferença de menus por perfil.

## Acessos de demonstração

- Vendedor: `vendedor@unifahe.com.br` / `123456`
- Gestor: `gestor@unifahe.com.br` / `123456`

## Perfis

### Vendedor
- Início
- Vendas
- Times
- FCA
- Campanhas
- Dashboard vendedor

### Gestor
- Início
- Vendas
- Times
- FCA
- Campanhas
- Dashboard vendedor
- Dashboard geral

## Observação importante

O login atual é somente de demonstração no frontend e não deve ser usado como autenticação real em produção. Para produção, conecte Firebase Auth, Supabase Auth ou outro backend seguro e faça a autorização de perfil também no servidor/banco.

## Executar

Abra `index.html` ou publique a pasta diretamente na Vercel.
